==================================================
2. O QUE É O WOIL
==================================================

Woil significa conceitualmente:

WATER + OIL.

Água e óleo coexistem, mas não se misturam.

Essa metáfora representa a filosofia do produto:

- conhecimento e estrutura;
- conteúdo e metadados;
- humano e agente;
- criatividade e desenvolvimento;
- elementos diferentes trabalhando juntos sem perder sua identidade.

O Woil é um aplicativo de Personal Knowledge Management (PKM).

Ele é inspirado em conceitos de ferramentas como Obsidian, mas NÃO deve ser tratado como um clone do Obsidian.

O objetivo é criar uma ferramenta própria.

O princípio central é:

O conhecimento pertence ao usuário.

A IA é uma camada que trabalha sobre esse conhecimento.

A IA não deve ser a dona dos dados.

3. VISÃO DO PRODUTO
==================================================

O Woil será um ambiente pessoal para:

- escrever;
- organizar ideias;
- conectar conhecimento;
- pesquisar;
- armazenar livros;
- organizar projetos;
- registrar informações;
- trabalhar com arquivos Markdown;
- futuramente trabalhar com áudio;

- futuramente utilizar agentes de IA de forma nativa.

A integração com agentes de IA é um diferencial arquitetural importante do Woil.

Entretanto:

NÃO comece construindo o agente.

Primeiro construa a fundação sobre a qual o agente poderá trabalhar.

==================================================
4. PRINCÍPIOS FUNDAMENTAIS
==================================================

Os seguintes princípios são fundamentais:

### Local-first

O usuário deve possuir seus dados.

O vault deve ser baseado em arquivos locais.

### Markdown como fonte de verdade

Notas devem existir como Markdown.

Não transformar o banco de dados da aplicação na fonte primária do conhecimento.

### Arquitetura extensível

A aplicação deverá permitir posteriormente:

- agentes;
- MCP;
- sincronização;
- busca semântica;
- plugins;
- automações;
- desktop;
- outras integrações.

Mas não implemente tudo agora.

### Mobile-first

O desenvolvimento inicial é Android.

A tecnologia inicial definida para o projeto é:

React Native + Expo.

Desktop será tratado posteriormente como uma experiência de workspace.

### UI separada da infraestrutura

A interface não deve manipular diretamente o filesystem.

Use camadas apropriadas.
